# IPTVnator archive review notes

Archive reviewed: `iptvnator-master(1).zip` (4,951 entries; approximately 212 MB uncompressed).

The archive's README describes IPTVnator as a cross-platform player built with Electron and Angular. Its listed functional areas include remote/local M3U/M3U8 playlists, XMLTV EPG, Xtream Codes and Stalker/Ministra portals, live playback, group/search/channel number navigation, VOD movie/series catalogues, favorites, recent/continue-watching, and platform-specific desktop playback/download features.

The included `LICENSE.md` is MIT, copyright (c) 2019–2026 4gray. This STBPlay starter was written as a new native Android codebase and uses the archive as a behavior/feature reference, not as a code port. The whole archive was not line-by-line audited; implementation work should inspect the relevant IPTVnator modules before any future source reuse.
